# HomeFeast – Homemade Tiffin & Food Service Platform

## Project Overview

HomeFeast is a web-based platform designed to connect customers with home cooks who provide homemade food and tiffin services.

## Main Features

* Customer registration and login
* Food menu browsing
* Online order placement
* Home cook dashboard
* Menu and order management
* Administrator management features

## User Roles

1. Customer
2. Home Cook
3. Administrator
